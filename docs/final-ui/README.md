# 약MI. 최종 레퍼런스 UI 적용

2026-11-13. 최신 6개 화면 포스터를 기준으로 기존 앱의 UI를 조정했습니다. 이전 로고 제거 요청보다 최신의 **기존 두 로고 유지** 지시를 우선했습니다.

## 변경 파일

- `components/home-screen.tsx`: 기존 SISIDETAIL SVG를 홈에 연결. 기존 약MI. 원본 이미지, 말풍선, 검색 및 2열 바로가기 유지.
- `components/scene-header.tsx`: 상세정보 제목을 공통 파란 헤더에 맞게 정리. 기존 약MI. 로고 유지.
- `components/detail-screen.tsx`: 기본정보 / 주의사항 / 성분 / 보관 탭 구현. 방향키·Home·End, 선택 상태, 탭 패널 접근성 지원. 모든 기존 의약품 정보에 접근 가능.
- `components/identify-screen.tsx`: 카메라 상태 PNG를 하단에 배치. 사진 선택 시 수동 식별 입력을 펼침. 사진 선택·촬영·미리보기·삭제 및 식별 검색 유지.
- `components/library-screen.tsx`: 6개 단위 페이지와 보관함 휴식 캐릭터. 기존 실제 저장 개수, 필터, 삭제, 최근 본 약 기능 유지.
- `app/globals.css`: 공통 라벤더 배경, 픽셀 헤더·탭, 도감 3열, 사진·휴식 캐릭터 영역, 중앙 최대 560px 레이아웃.
- `tests/browser-check.mjs`: 최신 로고 유지 기준, 상세 탭 전환, 사진 선택 후 입력 펼침, 휴식 캐릭터 검증 및 캡처 추가.

로고 정의 파일 `components/brand-logo.tsx`, 로고 원본 이미지, 캐릭터 PNG는 수정하지 않았습니다. API 서버 모듈·Route Handler·저장 데이터 구조·패키지 설정은 변경하지 않았습니다. 작업 전 UI 소스는 상위 작업 폴더의 `backups/yakmi-before-final-ui-20261113.zip`에 보관했습니다.

## 검수

- 프로덕션 빌드·TypeScript 검사 통과, ESLint 경고/오류 없음.
- Node 테스트 10개 통과.
- 375 / 430 / 768 / 1440px × 7개 경로, 28개 반응형 검사 통과. 가로 넘침 없음, 중앙 콘텐츠 최대 560px.
- 브라우저 실행 예외 및 누락 에셋 0건.
- 저장·즐겨찾기·최근 검색·최근 본 약 유지, 사진 미리보기·삭제, 서버에 사진을 전송하지 않음 확인.
- 4개 상세 탭 및 Home 키 전환, 사진 선택 후 입력 펼침 검증.
- 포션 4초 둥실 동작: 좌우 6px / 상하 5px / 기울기 1도. 이동 경로 19개 지점에서 부모·화면·UI에 잘리지 않음. reduced-motion 지원.

`browser-results.json`과 `screenshots/`에 결과를 보관했습니다. `TEST-ONLY` 파일은 격리된 검수 브라우저에서만 주입한 **가상의 UI 검증 자료**이며 실제 의약품 정보가 아닙니다. 앱·서버에는 테스트 의약품을 추가하지 않았습니다.

## 원본 대비 남은 차이와 미검증 항목

- 포스터 전체를 화면 배경으로 붙이지 않고 작동하는 HTML UI로 구성했습니다. 따라서 글꼴, 픽셀 테두리, 세부 구름·꽃 배치와 여백이 포스터와 완전히 같지는 않습니다. 특히 안내문·실제 정보 길이에 따라 화면 높이가 달라집니다.
- 기존 완성 로고를 변경하지 않아 포스터의 로고 렌더링과 차이가 남습니다. 두 로고의 파일·형태·색상은 보존했습니다.
- 캐릭터는 기존 ZIP의 투명 개별 PNG를 사용합니다. 새 첨부 포션 사진의 라벤더 배경을 UI 안에 사각형으로 붙이지 않았으며 새로 그리지 않았습니다.
- ZIP 애니메이션 일부 프레임에 원본 잘림·다른 조각이 있어 메인은 온전한 기본 PNG에 CSS 이동을 적용합니다. 8개 포즈 순환은 적용하지 않았습니다. 이동 애니메이션은 유지합니다.
- 실제 식약처 인증 성공 조회는 검증하지 못했습니다. 키 누락·오류 상태는 확인했고 키를 요청하거나 출력하지 않았습니다. 실제 이미지가 없는 경우 안내용 빈 이미지 영역을 사용합니다. 제공되는 약 사진에는 픽셀화를 적용하지 않습니다.
- 사진 자동 인식은 구현하지 않았습니다. 사진을 보면서 색상·모양·각인을 직접 입력하는 기존 식별 검색 방식입니다.
- 배포는 이번 UI 작업 범위에서 수행하지 않았습니다.
