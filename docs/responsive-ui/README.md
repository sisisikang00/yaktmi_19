# 약MI. 원본 UI 및 반응형 검수

2026-11-13. 최신 포스터의 6개 화면 구성을 유지하면서 모바일 높이, 포션 밑줄, 태블릿·PC 배치를 수정했습니다. 이 문서가 이전 `final-ui` 검수 이후의 최신 결과입니다.

## 수정 파일

- `components/potion-character.tsx`: 기본 PNG의 별도 밑줄을 표시하지 않는 클래스 적용. 원본 PNG 자체는 변경하지 않았습니다.
- `components/app-shell.tsx`: PC·태블릿 양옆 구름과 풀밭 배경, 넓은 화면의 하단 풍경 연결.
- `app/globals.css`: 모바일 홈 높이와 입력·버튼 간격, 캐릭터 이동 공간, 네이비 점선 사진 영역, 공통 픽셀 UI, 반응형 레이아웃.
- `tests/browser-check.mjs`: 실제 모바일 에뮬레이션, 짧은 화면 버튼 노출, PC 2열 홈, 밑줄 표시 제외, 4개 화면 너비 검수.

## 포션 아래 선

기본 PNG는 210×237px입니다. 병 바닥 외곽선은 y=200~207에 있고, 별도 검은 선은 y=218~220에 포함되어 있었습니다. PNG의 병 자체는 그대로 두고 y=208 이후의 불필요한 바닥 영역만 CSS 표시 마스크로 제외했습니다. 병 바닥과 캡슐은 보존했습니다. 캐릭터 요소의 border·box-shadow·가상 요소도 제거했고 추가 바닥 그림자는 만들지 않았습니다.

부유 애니메이션은 4초 주기, 좌우 6px·상하 5px·기울기 1도로 유지합니다. 부모 컨테이너를 자르지 않으며, 이동 공간을 확보했습니다. reduced-motion에서는 정지합니다.

## 화면 구성

- 모바일: 기존 브랜드 → 말풍선 → 포션 → 입력 → 검색 → 사진/모양 2열 → 하단 메뉴 순서. 작은 높이에서도 버튼이 메뉴 뒤로 숨지 않도록 조정.
- 태블릿: 최대 680px 콘텐츠, 모바일 순서 유지, 도감 간격과 이미지 영역 확대.
- PC: 최대 1120px. 홈은 브랜드·포션과 검색 컨트롤의 좌우 배치, 검색 결과는 2열 목록, 상세는 제품 요약과 정보 탭의 좌우 배치, 도감은 4열. 별도의 사이드바나 관리자 메뉴를 추가하지 않았습니다.
- 나머지 사진·도감·보관함 화면은 기존 수동 식별·저장·즐겨찾기·최근 기록 기능과 상태별 PNG를 유지합니다.

## 검증 결과

- Next.js 프로덕션 빌드 및 TypeScript 검사 통과.
- ESLint 오류·경고 없음. Node 테스트 10개 통과.
- 375 / 430 / 768 / 1440px × 7개 경로 = 28개 브라우저 반응형 검사 통과.
- 추가 375×667, 430×740 모바일에서 사진/모양 버튼이 하단 메뉴보다 위에 노출됨 확인.
- 애니메이션 19개 지점에서 캐릭터 이미지가 이동 공간·화면 경계·검색 UI를 벗어나지 않음. 시작·좌·우·상·하·반복 구간 캡처.
- 상세 4개 탭과 키보드 이동, 사진 선택 후 수동 입력 펼침, 미리보기·삭제, 저장·즐겨찾기·최근 검색·최근 본 약 확인.
- 브라우저 실행 예외 및 누락 이미지 0건.
- 작업 전 백업과 비교해 SISIDETAIL 로고 정의 및 API Route Handler 3개가 동일함 확인. 약MI. 로고 원본 이미지, 서버 API 모듈, 데이터 구조, 인증키 설정, 패키지는 수정하지 않았습니다.

캡처는 `screenshots/`, 기계 검수 결과는 `browser-results.json`에 있습니다. 파일명 `TEST-ONLY` 캡처는 검수 브라우저에서만 주입한 가상 문구입니다. 실제 의약품 자료·이미지로 사용하지 않았고 앱이나 서버에 테스트 약을 추가하지 않았습니다.

## 남은 차이와 검증 한계

- 작동하는 웹 UI이므로 포스터와 글꼴·일부 구름/꽃의 정확한 위치·줄바꿈·세부 여백은 다릅니다. 시스템 시계·휴대폰 테두리는 추가하지 않았습니다.
- 기존 로고를 변경하지 않았으므로 포스터의 로고 렌더링과 미세한 차이는 유지됩니다.
- 실제 의약품 정보 길이와 이미지 제공 여부에 따라 목록·상세 높이는 달라집니다. 사진이 없을 때는 안내용 영역을 사용하며 실제 약 사진에 픽셀화나 재생성을 적용하지 않습니다.
- 실제 식약처 인증 성공 조회는 확인하지 못했습니다. 기존 호출 방식을 유지했고 키 누락·오류 처리는 검증했습니다. 인증키를 요청하거나 출력하지 않았습니다.
- 사진 자동 인식은 구현한 것으로 표현하지 않습니다. 사진 미리보기와 수동 식별 검색 흐름을 유지합니다.
