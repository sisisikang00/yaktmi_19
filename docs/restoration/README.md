# 약MI. 최초 디자인 복원 결과

2026-11-13. 이번 복원은 상위 브랜드 로고 추가를 취소하고, 최초 홈·앱 콜라주·상세정보 레퍼런스의 세로형 화면으로 되돌리는 작업입니다.

## 수정 전 보존

코드 수정 전에 원본 소스·에셋·설정·문서를 [백업 ZIP](../../../backups/yakmi-before-original-restore-20261113-131734.zip)으로 보존했습니다. 의존성, 빌드 캐시, 실제 환경변수 파일은 포함하지 않았습니다.

백업과 SHA-256을 비교해 API 서버 모듈, Route Handler, localStorage 모듈, 데이터 타입, 패키지 및 Next 설정 등 14개 기능 파일이 이번 작업에서 변경되지 않았음을 확인했습니다.

## 복원한 항목

- 앱 상단/하단/로딩 화면의 SISIDETAIL 로고와 브랜드 바를 제거했습니다. 새로운 로고는 만들지 않았습니다.
- 홈 상단은 원본 PNG의 약MI. 로고·분홍색 마침표·구름·픽셀 하늘을 그대로 표시합니다.
- 말풍선, 검색 버튼, 사진/모양 2열 버튼도 원본 영역을 사용합니다.
- 임의로 만들었던 잔디 패턴은 원본 홈의 캐릭터 좌우 잔디 영역으로 바꿨습니다. 하단 꽃·약국 표지판 풍경도 원본을 사용합니다.
- 홈·검색·상세·사진·도감·보관함 모두 같은 세로형 앱과 하단 메뉴를 사용합니다. PC는 최대 560px 중앙 정렬이며 별도 메뉴나 사이드바가 없습니다.
- 상세 배너의 책·흰색 제목판을 최초 상세 레퍼런스 영역으로 복원했습니다. 효능·용량·주의·성분의 파스텔 구분은 유지했습니다.
- 검색, 상세 이동, 저장/즐겨찾기, 최근 검색/최근 본 약, 사진 미리보기와 수동 식별 기능을 보존했습니다.
- 실제 약 사진은 제공된 원본 URL을 `contain`/일반 렌더링으로 표시하며 픽셀 효과를 적용하지 않습니다.

## 캐릭터 잘림과 원본 파일 문제

ZIP의 일부 포즈 PNG를 개별 확인한 결과, `frame_04`~`frame_07`에는 이웃 캐릭터의 일부가 포함되어 있고 `frame_06`~`frame_08`에는 병 외곽이 이미 잘린 부분이 있습니다. 부모 여백이나 CSS 크기를 바꾸어도 파일 안에 없는 픽셀을 되살릴 수 없습니다.

따라서 홈은 ZIP의 **온전한 `states/idle.png`**를 그대로 사용하며, 원본을 다시 그리거나 누락 영역을 생성하지 않았습니다. 잘못 잘린 8개 포즈를 교차 표시하지 않습니다. 상태별 페이지는 기존의 개별 상태 PNG를 유지합니다. ZIP 원본 파일 자체는 수정하지 않았습니다.

움직임은 줄이지 않았습니다.

- 4초 동안 좌우 ±6px, 상하 ±5px, 회전 ±1°로 부드럽게 반복합니다.
- 캐릭터에만 transform을 적용하며 검색창·버튼·말풍선은 고정합니다.
- 원본 PNG의 실제 210×237 치수와 종횡비를 보존합니다. 표시 크기는 한 가지 배율로만 조정합니다.
- 캐릭터와 모든 홈 상위 요소의 overflow는 visible이며, 별도의 이동 안전 공간을 확보했습니다.
- `object-fit: contain`과 픽셀 렌더링을 사용합니다.
- 움직임 줄이기 설정에서는 온전한 기본 PNG를 정지 표시합니다.

375px에서 0~4.25초 사이 19개 시점의 이미지 전체 경계와 부모/화면 경계를 비교했습니다. 시작, 좌, 우, 상, 하, 반복 순간 모두 안전 영역 안에 있고, 잘리는 조상 요소가 없으며 검색창과 겹치지 않았습니다. 측정값은 [브라우저 결과 JSON](./browser-results.json)에 있습니다.

## 검증 결과

- ESLint 및 Next.js production build/TypeScript 통과.
- 서버 보안·파싱 8개, 원본 PNG/투명도 2개 테스트 통과.
- 375/430/768/1440px × 7개 화면: 28개 반응형 검사 통과. 가로 넘침 없음, 최대 560px, 하단 메뉴와 홈 버튼 2열 유지.
- 모든 화면과 로딩에서 SISIDETAIL 로고 DOM이 없음을 확인.
- 19개 이동 시점의 캐릭터 경계, ±6px/±5px 이동, 4초 주기, UI 고정, reduced-motion 통과.
- 저장·즐겨찾기·최근 검색·최근 본 약 유지 및 사진 선택/지우기/미업로드 확인.
- 런타임 예외·누락 에셋 없음.
- API·저장·프로젝트 설정 파일 14개가 백업과 동일함을 확인.

## 원본 대비 남은 차이

1. 레퍼런스의 정지 포션 그림과 ZIP의 온전한 기본 PNG는 그림의 질감·여백·작은 표정이 완전히 같지는 않습니다. 지정된 ZIP 원본을 사용했으며 새로 그리지 않았습니다.
2. 손상된 8개 포즈 교차 재생은 사용하지 않습니다. 대신 온전한 기본 포션의 4초 둥실 움직임을 유지합니다. 포즈 교차 재생까지 필요하면 이웃 조각과 잘린 병이 없는 개별 프레임 원본이 필요합니다.
3. 잘림을 방지하기 위한 캐릭터 이동 여백이 정지 레퍼런스보다 넓습니다. 휴대폰 상태바·외곽 프레임은 웹 UI에 넣지 않았습니다.
4. 입력창과 실제 정보 본문의 한글은 시스템 폰트라 원본 이미지 속 글꼴과 자간에 차이가 있습니다. 원본 로고·말풍선·홈 기능 버튼의 글자는 그대로입니다.
5. 원본 PNG 표시 영역끼리 연결되는 곳의 미세한 배경 색조 경계와, 화면 높이에 따라 달라지는 여백이 남습니다. 화면 전체가 픽셀 단위로 일치한다고 주장하지 않습니다.
6. 결과 수·사진·내용은 실제 데이터에 따라 달라집니다. 인증키 미설정으로 식약처 실조회 성공은 이번에도 검증하지 못했습니다. 기존 API 연결 코드와 보안 정책은 유지했습니다.
